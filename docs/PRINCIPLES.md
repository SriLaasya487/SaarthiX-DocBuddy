# Core Principles

1. **Elder consent first.** Every share, alert and escalation needs the elder's prior or live approval. Revocable in one sentence.
2. **Never diagnose.** Suggest doctor types, show doctor-approved instructions, give information only. Avoids medical-device and liability issues.
3. **Voice first, large and simple.** Regional languages, dialect tolerance, big buttons, "Hear it again" / "Slow down".
4. **Confirm before saving.** OCR scans, post-visit notes and voice-logged vitals are saved only after elder confirmation.
5. **Auditable.** Every data access is logged and can be read back in plain language.
6. **Works for everyone.** Offline mode, low-end phones, feature-phone IVR.
